# 页间 dev.31 测试版

本版将 AI 助手实验功能并入常规 Android 测试版，同时改进角色卡与世界观的整理体验。

- AI 助手支持保存并切换多组自备 API 配置；正文中可按选区、段落或光标位置发起操作，预览结果后再决定是否采用。
- 文风模板与操作提示词分别管理：内置模板可编辑、删除，也可自行新增多个模板；最近生成结果移至独立的历史页面。
- 角色卡和世界观的长文本字段可放大到独立页面编辑；列表支持按分类标签筛选，也可长按卡片或点击“排序”调整顺序。
- 修复已有“人物关系”无法再次修改的问题。相关反馈见 [#7](https://github.com/silent07137/yejian-novel-studio/issues/7)。

这是开发测试版。升级前建议先导出 `.sns` 或 `.snss` 工程备份。AI 功能仅在用户主动配置并确认使用时请求所选服务商；API Key 保存在设备安全存储，不包含在工程文件中。欢迎通过 [GitHub Issues](https://github.com/silent07137/yejian-novel-studio/issues) 反馈问题。
