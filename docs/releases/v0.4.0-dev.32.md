# 页间 dev.32 测试版

本版新增平板布局，手机端仍保留原有的悬浮胶囊导航。

- 平板使用左侧窄导航栏；打开作品后，写作页可同时查看章节目录与正文，宽屏横向布局还可显示本章笔记。
- 角色卡与世界观在平板上采用列表、详情分栏，方便筛选和查阅，不影响手机端的卡片式页面。
- 调整正文工具栏以适应分栏宽度，修复章节目录与正文滚动位置在尺寸切换时的状态冲突。

已通过自动化测试，并在 Android 模拟平板竖屏、横屏下检查主要页面。此版本仍是开发测试版；升级前建议导出 `.sns` 或 `.snss` 工程备份。如有问题，欢迎通过 [GitHub Issues](https://github.com/silent07137/yejian-novel-studio/issues) 反馈。
