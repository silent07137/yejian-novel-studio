# 页间 dev.21 测试版

本版加入 Markdown 正文编辑和最基础的正文插图能力，供协同者测试。

- 写作页新增 Markdown 常用格式菜单，可插入标题、加粗、斜体、引用、列表和行内代码；支持在源码与排版预览之间切换。
- 可从本机选择 PNG、JPEG 或 WebP 图片，插入为独立段落；图片上下是正文，不做文字环绕。单张图片限制 32 MB。
- 正文图片随 `.sns/.snss` 工程文件备份和恢复。带图 Markdown 导出为包含 `.md` 与图片的 ZIP；TXT 导出显示图片说明。
- 修复保存尚未结束就退出编辑页时可能触发的释放后通知错误。

这是开发测试版。请先导出工程备份，再升级或跨设备迁移；欢迎在 [GitHub Issues](https://github.com/silent07137/yejian-novel-studio/issues) 反馈编辑与插图体验。
