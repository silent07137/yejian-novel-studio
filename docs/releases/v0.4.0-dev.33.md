# 页间 0.4.0-dev.33 双端测试版

本次同时提供 **Android APK** 和 **Windows x64 MSI 安装包**，保留现有写作、设定、情节与 AI 功能。更新前请先导出工程备份；本版仍为预发布测试版。

## Windows

- 修复读取旧数据时“Cannot add to an unmodifiable list”的启动失败。
- 修正应用图标与窗口中文标题。
- 安装时选择父目录，自动在其下创建 `yejian` 文件夹；本地数据保存在该目录的 `user-data` 中。
- 首次运行可复制旧版 AppData 数据，保留原文件；卸载不主动删除写作数据。

## 写作与界面修复

- 桌面参考栏的“本章笔记”可直接编辑，并与章节大纲同步；角色卡可悬停查看概要、点击打开详情。
- 压缩桌面设定页的重复标题与操作区，增加双栏详情可用空间。
- 修复在目录中修改章节标题后编辑器未同步、切章动画中的旧编辑器可能写入新章节的问题。
- 搜索结果可打开具体角色、世界观及事件；长事件详情可滚动查看。
- 长篇 Markdown 预览独立滚动；预览中可修改图片宽度及说明，仅调整宽度也立即生效，并随工程保存。

## 工程备份与加载

- `.sns/.snss` 升级为 v3 分文件 ZIP：作品信息、分卷、每章正文、角色、世界观、情节及资源分开保存。
- 本地数据库按章节／模块读取，保存时保留尚未加载的内容，避免只打开一章后覆盖其他正文。
- 导入解析移至后台；优化字数统计缓存、重复保存与正文输入时的全局界面重建。
- 仍可导入旧版 v1/v2 工程和旧 JSON 数据；**旧版应用无法读取本版新导出的 v3 工程**，跨设备使用请同步升级。

## 验证与注意事项

- 本地静态分析通过；包含真机导出校验的 108 项测试通过。
- Android 真机已验证导入、切章、长文预览、插图尺寸修改及工程导出；11 章样本正文与标题往返一致。私人样本不随发行包或源码公开。
- Windows Release 与 MSI 已完成本地构建；实际安装升级、更多桌面交互和百万字性能仍需协同测试，不把局部性能测试视为整体流畅度验收。

- 两端构建与校验全部成功后才公开本条预发布；下载后可核对随包提供的 SHA-256。
