# 页间重做实现状态

本文件以《页间双端开发手册 v1.0》为验收依据。界面存在不等于功能完成；每项只使用以下状态：

- `not_started`：尚未实现。
- `layout_only`：已有界面或入口，数据闭环尚不完整。
- `data_connected`：真实读写已经接通，尚未完成双端平台验证。
- `platform_verified`：已在目标平台验证，尚未走完人工验收。
- `accepted`：手册对应验收项已执行并留有证据。

## 明确不应被宣称为完成

- 当前角色/世界观基础编辑闭环已接通，但模板、字段管理、标签库、草稿与恢复 UI 尚未完成。
- 当前时间轴、思维导图、流程图已是可交互的独立画布，但节点拖拽布局、连线编辑、布局持久化和全屏编辑仍未完成。
- `.sns/.snss` 已有版本化工程格式与旧 JSON 兼容读取，但跨设备实机恢复仍待验收。
- EPUB/DOCX/PDF、搜索、历史页、回收站、性能与无障碍验收尚未完成。
- Android 15 AVD 已通过全新安装、冷启动、基础导航与数据恢复验证，但不能将模拟器结果写成实体手机通过。
