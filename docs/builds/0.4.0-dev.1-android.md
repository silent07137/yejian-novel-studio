## 本次启动修复

- 根因：Android `sqflite` 不允许用 `execute()` 执行会返回数据行的 `PRAGMA busy_timeout`，导致数据库打开异常发生在 `runApp()` 之前，界面停在启动画面。
- 修复：改用 `rawQuery()` 执行有返回值的 PRAGMA，并将应用启动改为可见的异步引导层；后续初始化失败时会显示错误和“重试”，不再无限白屏。
