## 修复内容

### 书架与作品首页

- 书架书卡不再直接跳到正文，先打开独立作品首页。
- 作品首页展示封面、书名、作者、简介、字数、章数、卷数和修改日期。
- 提供“继续写作/写第一章”、编辑资料、更换封面以及写作/设定/情节/导出入口。
- 增加可见的分卷章节目录；点击章节进入对应正文，可在卷内或全局新建章节。
- 手机正文顶部原有的无文字目录图标改为“目录”图标加文字入口。
- 作品首页补齐底部系统导航安全区。

### 新建角色

- 根因：新建角色的姓名默认为空，头像代码直接读取首字符，触发 `Bad state: No element`。
- 修复：空姓名时使用“未”作为头像占位，输入姓名后实时更新。
- 已验证空白角色表单打开、输入、保存、列表回显与冷重启持久化。
