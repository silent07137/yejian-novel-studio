# 0.4.0.ai.dev 测试说明

此版本在 `feature/ai-0.4.0-dev` 分支试验 AI 润色与续写，尚不属于主线稳定功能。

## 使用方法

1. 在「设置 → 应用设置 → 配置 AI 服务」填写支持 Chat Completions 的 HTTPS API 地址（以 `/v1` 等基础路径结尾）、模型 ID 和自己的 API Key。
2. 在章节正文中选中文字，使用选字菜单中的「AI 润色／AI 续写」，或键盘上方工具栏的 AI 菜单。
3. 核对接收文字的服务商域名，确认发送。生成结果先预览；只有点「替换选区／插入续写」才会修改正文。

默认不发送整章、角色卡或工程文件。Key 放在设备安全存储中，不写入 `.sns`、`.snss` 或仓库。服务商可能产生费用，请使用自己的 Key，不要将开发者 Key 嵌入安装包。

## 当前边界

- 仅支持 Chat Completions 兼容接口；不等于支持 Gemini、Claude 等原生 API。
- 为保护 Key，只接受 HTTPS；局域网明文 HTTP、本地模型与服务端代理尚未接入。
- 一次最多处理 8000 字符，图片标记不可送入 AI。
- 尚无流式输出与请求取消。离开页面不会自动插入 AI 回复。
