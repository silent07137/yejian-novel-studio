# 0.4.0.ai.dev 测试说明

此版本在 `feature/ai-0.4.0-dev` 分支试验 AI 编辑功能，尚不属于主线稳定功能。

## 使用方法

1. 在「设置 → 应用设置 → AI 助手」添加 API 配置，可保存多组并点选默认配置；旧版单组配置会自动显示为「原有配置」。每组填写支持 Chat Completions 的 HTTPS API 地址（以 `/v1` 等基础路径结尾）、模型 ID 和自己的 API Key。
2. 同页可新建、命名多个文风模板。默认提供「默认、细腻抒情、简洁克制、悬疑紧凑」；内置模板也可编辑或删除，删除后可恢复。每个模板可设置文风要求，也能单独覆盖润色、续写、改写和自定义操作的提示词。旧版共用提示词自动迁移为「原有提示词」模板。
3. 在章节编辑器顶部点「AI 助手」。选字菜单保留系统操作和「添加标注」，不再放置多个 AI 选项。AI 面板里可为本次请求选择模型配置和文风模板，不改变默认选择，再选择润色、续写、改写或自定义指令。
4. 有选区时默认处理选中文字；无选区时，润色、改写和自定义默认处理当前段落，续写默认使用光标前文并在光标处插入。也可明确切换为整章（最多 8000 字符）。
5. 发送前核对服务商域名、正文范围、当前提示词及作品参考资料。默认附带当前章节附近文字和匹配的角色、世界观、时间线资料，可在面板内关闭。只有点「确认发送」才会请求服务。
6. 生成结果与原文对照预览；只有点「替换正文／插入续写」才会修改正文，也可以只复制结果。成功生成的结果会进入「生成历史」，累计次数不会因旧结果被裁剪而减少；可选择保留最近 20、50、100 或 200 条。

发送内容包括选定范围文字、当前操作提示词，以及你在面板中选择附带的作品参考资料。附近正文最多截取约 1200 字符；短章节可能完整落入该片段，因此发送前请检查列表或关闭附带资料。整章仅在用户主动选择时发送，不会自动发送整本书或工程文件。多组 API Key 与自定义提示词保存在设备安全存储中；生成结果历史保存在本机独立文件，包含生成结果但不含 API Key 或原文请求，均不写入 `.sns`、`.snss` 或仓库。服务商可能产生费用，请使用自己的 Key，不要将开发者 Key 嵌入安装包。

## 当前边界

- 仅支持 Chat Completions 兼容接口；不等于支持 Gemini、Claude 等原生 API。
- 为保护 Key，只接受 HTTPS；局域网明文 HTTP、本地模型与服务端代理尚未接入。
- 一次最多处理 8000 字符，图片标记不可送入 AI。
- 相关资料按名称与附近正文匹配，不是全书 RAG 检索；可能漏掉别名、隐含关系或没有直接提及的设定。
- 尚无流式输出与请求取消。离开页面不会自动插入 AI 回复。
