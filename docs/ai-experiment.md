# 0.4.0.ai.dev 测试说明

此版本在 `feature/ai-0.4.0-dev` 分支试验 AI 编辑功能，尚不属于主线稳定功能。

## 使用方法

1. 在「设置 → 应用设置 → 配置 AI 服务」填写支持 Chat Completions 的 HTTPS API 地址（以 `/v1` 等基础路径结尾）、模型 ID 和自己的 API Key。可在同页「编辑 AI 提示词」分别修改润色、续写、改写和自定义操作的提示词；不修改时使用内置版本，也可随时恢复默认。
2. 在章节正文中选中文字，使用选字菜单或键盘上方 AI 菜单，选择润色、续写、改写或自定义指令。自定义指令每次单独填写。
3. 发送前核对服务商域名、所选文字及页面列出的作品参考资料。默认附带当前章节附近文字和匹配的角色、世界观、时间线资料，可在确认框内关闭。
4. 生成结果与原文对照预览；只有点「替换选区／插入续写」才会修改正文，也可以只复制结果。

发送内容包括所选文字、当前操作提示词，以及你在确认框中选择附带的作品参考资料。附近正文最多截取约 1200 字符；短章节可能完整落入该片段，因此发送前请检查列表或关闭附带资料。不会自动发送整本书或工程文件。自定义提示词和 Key 放在设备安全存储中，不写入 `.sns`、`.snss` 或仓库。服务商可能产生费用，请使用自己的 Key，不要将开发者 Key 嵌入安装包。

## 当前边界

- 仅支持 Chat Completions 兼容接口；不等于支持 Gemini、Claude 等原生 API。
- 为保护 Key，只接受 HTTPS；局域网明文 HTTP、本地模型与服务端代理尚未接入。
- 一次最多处理 8000 字符，图片标记不可送入 AI。
- 相关资料按名称与附近正文匹配，不是全书 RAG 检索；可能漏掉别名、隐含关系或没有直接提及的设定。
- 尚无流式输出与请求取消。离开页面不会自动插入 AI 回复。
