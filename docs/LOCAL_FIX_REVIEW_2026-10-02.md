## 实现

- 桌面写作参考栏：本章笔记可编辑，与章节大纲共用 `summary`；角色／世界观可查看与跳转，角色悬停提示概要。
- 桌面设定双栏压缩顶部操作区，移除重复标题和新建入口；移动布局保持原逻辑。
- 章节标题内外修改即时同步；光标移动不触发重复保存；切章动画的旧编辑器不写入新章节。
- 搜索角色、世界观和事件打开具体命中条目；长事件详情可滚动，底部编辑操作保留可见。
- Markdown 改为独立有界滚动列表；预览图片可调整 10%–100% 正文宽度与说明，尺寸随数据库及 SNS 往返保存。
- SNS v3 分文件 ZIP，兼容旧 v1/v2；SQLite v3 元数据启动、正文按章、设定按模块读取，保存保留未加载内容。
- 字数缓存随正文修改失效；正文输入不再触发整个 MaterialApp 主题重建；跳过未更改章节的正文序列化。
- 保存调用串行化，导入解析使用后台 isolate；导入事务后元数据刷新失败则保留已保存候选书架，不丢弃已提交内容。
- 升级旧数据库不依赖 Android SQLite 的 JSON 扩展；SNS 导出尺寸／条目限制与读取限制一致；异步切书时按捕获的作品／章节配对加载。
